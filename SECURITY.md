# Security Policy

## Reporting Security Issues

If you believe you have found a security issue affecting Usul Learning, please report it by email:

contact@usullearning.com

Please include:

- A clear description of the issue
- Steps to reproduce, if applicable
- The affected URL or component
- Relevant screenshots or request details

## Scope

This policy applies to https://usullearning.com.

## No Bug Bounty

Usul Learning does not currently operate a bug bounty program.

## Responsible Disclosure

Please do not publicly disclose security issues before they have had reasonable review.
